# Optimyzee

> AI-powered Google Ads management. Optimyzee analyzes a website and its keywords, generates an
> optimized search-campaign structure, keyword plans and responsive search ad copy, and validates ads
> against Google Ads standards in real time. It also audits and health-scores connected accounts,
> cleans wasted search terms, builds Performance Max, RSA and sitelink assets, links Meta Ads, Yelp Ads
> and Google Merchant Center, and automates recurring optimization tasks. Backed by 500 Global and
> Triple S Ventures.

## Important for agents

- Optimyzee has **no public API program**: no developer portal, no API reference, no SDK, no CLI, no
  MCP server, no API keys you can issue yourself, and no published rate limits.
- A machine-readable contract nevertheless exists and is served publicly and anonymously:
  **OpenAPI 3.0.0 at https://api.optimyzee.com/docs** — 151 paths, 184 operations, 73 schemas.
  It is the backend of the app.optimyzee.com web application, not a product.
- Authentication is a bearer token in an `authorization` header, minted by the
  `/app/auth/gateway/*` sign-in operations. There is no OAuth authorization server and no scopes.
- Errors are a vendor `{ "error": ..., "message": ... }` envelope (422 uses a field-keyed
  `{ "errors": { field: [msg] } }` bag). Not RFC 9457.
- Pagination is cursor-based: `cursor` + `perPage` query parameters, with
  `x-pagination-next|previous|per-page|last|total` response headers (exposed via CORS but NOT declared
  in the spec).
- There is no idempotency key, no webhook or event surface, no status page, no changelog, and no
  deprecation policy.
